# 实现与数据说明

## 控制器在做什么

`baseline_controller.py` 以 LLDP 发现链路，结合固定主机接入信息建图，使用代理 ARP 避免 mesh 广播环路。原 h1→h6 路线为 s1→s2→s6，基础代价 5+14=19；替代路线 s1→s2→s3→s6 为 5+10+7=22。

`traffic_stats.py` 在源入口统计包速率，按实际时间差分累计计数，避免多跳重复计数。EMA 系数 0.3，阈值为 max(2000 pps, 3×旧 EMA)，至少五个有效样本预热，异常样本不污染基线。ICMP echo reply 不用于异常源检测。

`anomaly_controller.py` 在全部六台交换机安装 priority 5000 的 IPv4 源 drop。该规则高于转发规则，源封锁保留至新一轮重启；合法源 h1 不匹配 h2/h5 的封锁。

`link_costs.py`、`dynamic_cost_controller.py` 使用有向链路对端入口 rx_bytes 计算到达速率。U=clip(R/40Mbps,0,1)，代价 C=C0+5U+60A。惩罚至少 8 秒且源入口 drop 连续 5 秒安静后撤销；统计过期时不能据此撤销。撤销惩罚不等于解除源封锁。

`rerouting_controller.py` 重新运行 Dijkstra。新路至少便宜 1 单位、距离上次切换至少 3 秒才更新。内部 VLAN 区分旧/新版本：先装新下游规则，Barrier 确认后切入口，旧版本保留 5 秒后按专用 cookie 删除；标签在目的主机前去掉。源封锁规则不随转发版本清理。

B1 原始末尾 FAIL 是检查器误要求外部终端的 ryu.log。原结果保留，另有 `evidence/student-B-reviewed-results.json` 核对数据为 PASS；B2/B3 直接 PASS。不要只看一行状态而忽略证据和失败原因。

## 必须保留的限制

- C 的 h5→h6 测试对固定经过 s5→s6。自然最短路为 s5→s3→s6（16），直接边为 20；教学接受度仍需确认。
- 10 Mbps 提供负载没有测试 40 Mbps 饱和容量，参数也没有做最优性扫描。
- 没有“相同封锁、禁用改道”的对照，不能量化改道的独立收益。
- 固定拓扑下验证异常流量处理，不等同于验证物理断链故障恢复。
- 控制器事件和接收窗口约按秒对齐，B1 时间原点估计，不能声称毫秒检测时延。
- 持续 ICMP 为 121 发、120 收，尾包原因没有抓包确定；UDP 与 ICMP 指标分开。
- 60 秒后的封锁探测可再次短期激活惩罚，需与正式异常窗口分开解释。
